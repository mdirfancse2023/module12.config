# module12.config

## Spring Boot Concepts Covered by Module 1 to Module 12

This repository contains practical Spring Boot exercises from Module 1 through Module 12. Each module focuses on a specific concept and builds on the previous ones.

### Module 1
- Basic Spring Boot application setup and project structure.

### Module 2
- Validation annotations and custom validators.
- DTO/entity handling and controller-based request processing.

### Module 3
- CRUD operations with Spring MVC.
- Entity and repository design for simple business logic.

### Module 4
- External API integration and configuration.
- Working with service classes and response mapping.

### Module 5
- Spring Security basics.
- Authentication and authorization flow.

### Module 6
- RESTful web services and controller design.
- Structured API development.

### Module 7
- Spring Data JPA and repository interfaces.
- Database interaction using entities.

### Module 8
- Logging, monitoring, and application configuration.
- Better debugging and runtime observability.

### Module 9
- Exception handling and validation improvements.
- Cleaner API error responses.

### Module 10
- Service-oriented architecture basics.
- Separation of concerns across controllers, services, and repositories.

### Module 11
- Microservice communication and configuration management.
- Working with multiple Spring Boot applications.

### Module 12
- API Gateway, Eureka discovery, and distributed service setup.
- Config server and service orchestration concepts.
