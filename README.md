# module12.config

## Available Modules and Concepts Covered

The repository currently contains the following modules, each with its own Spring Boot concept focus:

### Module 1
- Introduces the basics of a Spring Boot project, including application setup, package structure, and how a simple application starts.

### Module 2
- Focuses on validation in Spring Boot using annotations and custom validators to enforce business rules on input data.

### Module 3
- Covers CRUD operations with controllers, services, entities, and repositories for handling simple database-backed business logic.

### Module 4
- Demonstrates integration with external services and mapping responses into Spring Boot applications.

### Module 5
- Explains Spring Security fundamentals, including authentication flow and securing application endpoints.

### Module 7
- Shows how Spring Data JPA is used for database access, entity mapping, and repository-based data operations.

### Module 12
- Focuses on microservice architecture concepts such as API Gateway, service discovery, and centralized configuration setup.
